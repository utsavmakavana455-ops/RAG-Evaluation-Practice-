# RAG Evaluation Practice 🔎

## Overview

Practical exercises on evaluating Retrieval-Augmented Generation (RAG) systems.

## Topics Covered

- Context Relevance
- Context Completeness
- Faithfulness / Groundedness
- Answer Relevance
- Hallucination Detection
- Evidence-Based Evaluation

## RAG Workflow

Question → Retrieve Documents → Retrieve Context → LLM → Answer

## Practice

I evaluated RAG examples using:

- Relevant vs. irrelevant context
- Complete vs. incomplete context
- Grounded vs. unsupported answers
- Relevant vs. irrelevant responses

## Key Learning

A retrieved context can be relevant but incomplete, while an answer can be relevant but not fully supported by the retrieved context.
